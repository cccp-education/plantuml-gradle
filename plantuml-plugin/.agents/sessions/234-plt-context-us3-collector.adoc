== Livré

=== Baby-step A — domaine pur `plantuml.context` (provenance, D-6)

* `ProvenanceSource` (data class) : `fileName` + `chars` + `tokens` (mesures).
* `ProvenanceChannel` (data class) : `channel` + `sources` + `totalChars()`/`totalTokens()`.
* `ContextProvenance` (data class) : `channels` + totaux dérivés + `toJson()`
  (Jackson `INDENT_OUTPUT`, schéma `{ channels, totalChars, totalTokens }`).
* `ProvenanceTracker` (accumulateur mutable) : `trackChannel` (last-write-wins,
  ignore une liste vide), `retainOnly` (élagage aux canaux survivants), `build`
  (snapshot immuable).
* Extension **additive** de `PlantumlContextBuilder.build(composite, budget, tracker)`
  (`tracker: ProvenanceTracker? = null`) : élague le tracker aux canaux ayant
  survécu au budget. Backward compatible (défaut nul = zéro tracking).

=== Baby-step B — tâche Gradle `collectPlantumlAugmentedContext`

* `CollectPlantumlAugmentedContextTask` (`@DisableCachingByDefault`) :
  * entrées : `eagerFiles` (`@InputFiles` RELATIVE), `ragContent`/`graphifyContent`/
    `docsContent` (`@Input @Optional`), `tokenBudget` (`@Input`) ;
  * sorties : `outputFile` (`build/plantuml/augmented-context.txt`) +
    `provenanceFile` (`build/plantuml/context-provenance.json`) ;
  * `run()` : construit `CompositeContext`, track les sources, `build` via le builder
    (tracker), écrit l'artefact + la provenance, log `PLANTUML CONTEXT`/`PLANTUML PROVENANCE`,
    warn si contexte vide.
* Enregistrement dans `PlantumlManager.Tasks.registerCollectAugmentedContextTask` :
  EAGER = `.agents/INDEX.adoc` + `PROMPT_REPRISE.adoc` + `AGENT.adoc` ; canaux via
  `-Pcontext.{ragContent,graphifyContent,docsContent,tokenBudget}`.
* i18n : `task.context.group` / `task.context.description` ajoutés aux **10** `Messages*.properties`.
