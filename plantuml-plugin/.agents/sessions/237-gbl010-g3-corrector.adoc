== Mission

EPIC transverse **GBL-010** (arbre de traduction), branche Data, **G-3 (reste)** : la
feuille `[plantuml]` **corrige** les blocs qui ne convergent pas — réparation
**déterministe** (`\n`) puis **assistée par IA** — toujours derrière le **round-trip**
(D5 : un bloc qui ne re-parse pas est rejeté, la source est préservée).

== Livrable — domaine pur `plantuml.repair` + adaptateur IA

* `PlantumlBlockRepairer` — **port** (`fun interface`) : `repair(source): String?`
  (propose une source corrigée, jamais acceptée sans round-trip).
* `PlantumlCorrectionStrategy` — enum `DETERMINISTIC` / `AI` / `PRESERVED`.
* `PlantumlBlockCorrection` — data class `source` + `status` + `strategy`
  (`corrected` = stratégie ≠ PRESERVED).
* `PlantumlBlockCorrector` — objet **pur** : pipeline
  1. déterministe (`PlantumlLabelIntegrity.repair` sur un label cassé D2) ;
  2. IA (port injecté) **acceptée seulement si elle re-parse** ;
  3. sinon source préservée verbatim.
  Un bloc déjà `TRANSLATED`/`MISSING` est un no-op (`PRESERVED`).
* `ChatModelBlockRepairer` — **adaptateur de référence** du port : prompt
  (English only) → `ChatModel.chat` → extraction via `LlmCodeExtractor` (PLT-AGENT
  DIA-04, fenced puis `@startuml…@enduml`). Ne valide pas (le correcteur tient la porte).

*Frontière* : le **domaine pur** (pipeline) + l'adaptateur ; le round-trip est le N0
`PlantUmlSyntaxValidator`. La feuille est consommée par l'arbre unifié G-4.
