== Contexte

`PLT-OUT-2` du backlog (`EPIC PLT-I18N-OUTPUT`) : les notes PlantUML doivent
être **couvertes** (multi-lignes, non quotées), **corrigées avant écriture**
(échappements `\n`, guillemets introduits) et un bloc non corrigeable doit être
`PRESERVE` (jamais publié cassé). L'audit a révélé un défaut réel non couvert :
la note flottante **quotée** `note "Warning: see below" as N1` était lue comme
une note multi-lignes — le `:` **dans les guillemets** ouvrait une fausse note
qui avalait le reste du diagramme.

== Livré (baby-step DDD/TDD/BDD)

=== Domaine `plantuml.repair` — extracteur

* `PlantumlNoteExtractor` reconnaît la forme flottante quotée
  `note "text" as N` (`QUOTED_START`) **avant** la forme `note … : text` :
  la note est `singleLine = true`, `quoted = true`, `raw` = texte intérieur
  (sans guillemets) et `text` = version trimée. Le alias `as N` et les
  guillemets ne sont jamais touchés ; un `:` dans les guillemets n'ouvre plus
  de bloc.
* `PlantumlNote.quoted` (additif, défaut `false`) porte ce discriminant.

=== Domaine `plantuml.repair` — intégrité

* `PlantumlLabelIntegrity.escapeQuotes` : échappe un guillemet introduit par le
  fournisseur (`"` → `\"`), idempotent sur un guillemet déjà échappé. Un
  guillemet non échappé fermerait le littéral et casserait le diagramme.

=== Port N0 `PlantumlTranslationPortAdapter`

* Les **libellés quotés** (y compris les notes quotées vues par la surface N0)
  sont réécrits avec `escapeQuotes(escapeNewlines(...))`.
* Les **notes** : cible = littéral quoté exact (`"raw"`) pour une note quotée,
  remplacement quoté et échappé ; alias préservé. Le contrat N0 interdit une
  traduction blanche (`TranslationResult.Success` exige un texte non blanc) ;
  un échec fournisseur préserve la source, et le port garde une garde
  défensive contre un résultat blanc.
* Round-trip : un bloc dont la traduction ne re-parse pas reste `PRESERVE`
  (raison « translation breaks PlantUML syntax »).

=== Tests (3 niveaux)

* Unit : `PlantumlNoteExtractorTest` (+5 : note quotée, `:` dans les quotes,
  raw intérieur exact, échappement `\n` littéral) ; `PlantumlLabelIntegrityTest`

  (+7 : note quotée sans corruption d'alias, `:` quoté, guillemet échappé
  label/note, contrat N0 rejette une traduction blanche, `\n` littéral restauré,

* Functional : `PlantumlNoteTranslationFunctionalTest` (3, **vrai**

* BDD : `34_plantuml_notes.feature` +3 scénarios `@plantuml-notes`
