== Mission

EPIC transverse **GBL-010** (arbre de traduction du site), branche Data, **G-3b** :
la feuille `[plantuml]` expose, **par bloc**, un **statut de traduction**
(`MISSING`/`PENDING`/`TRANSLATED`/`BROKEN`) et la **version de référence du
toolchain**, lisibles par document/cheroliv (audit d'arbre unifié G-4). Consomme
`PLT-DIAGRAM-OWNERSHIP` (GBL-007) — ne le refait pas.

== Livrable — domaine pur `plantuml.repair`

* `PlantumlBlockStatus` — enum `MISSING` / `PENDING` / `TRANSLATED` / `BROKEN`
  (vocabulaire du modèle d'arbre GBL-010).
* `PlantumlBlockEntry` — data class `ref` + `status` + `owner` (défaut `plantuml`,
  invariant `ref` non vide). Le **propriétaire unique** de la feuille.
* `PlantumlBlockClassifier` — objet pur `classify(source, validator)` :
  1. source blanche → `MISSING` ;
  2. label quoté sur retour-ligne réel (`PlantumlLabelIntegrity.hasBrokenQuotedLabel`,
     le défaut D2/CHE-DIAGRAM) → `BROKEN` (précède l'oracle) ;
  3. pas de validateur → `PENDING` ;
  4. oracle N0 `PlantUmlSyntaxValidator` valide → `TRANSLATED` ;
  5. oracle invalide → `PENDING` (correction assistée IA = G-3, restant).
* `PlantumlBlockReport` — data class `blocks` + `toolchain`
  (`PlantUmlToolchainReference`, D6) + `owner` (`plantuml`) → `toJson()`
  (Jackson `INDENT_OUTPUT`) : l'artefact lisible par G-4.

*Décision de frontière* : le **domaine pur** (API + JSON) est la feuille exposée ; **pas
de tâche Gradle** — la marche de l'AST (surface des blocs `[plantuml]`) appartient à
document (G-2) et la fusion des 3 rapports à cheroliv (G-4). plantuml fournit le
classifieur, jamais un moteur de parcours (DAG : un nœud, un propriétaire).
