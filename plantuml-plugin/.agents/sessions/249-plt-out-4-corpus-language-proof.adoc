(`SourceLanguageResidue`, S-248) en **mesure sur corpus réel**, non bloquante,
et produire la **preuve** « avant » des blocs EN encore français. Aucun run LLM
metered (la re-traduction reste une session `cheroliv.com`).

== Cadrage (`.agents/CADRAGE_PLT_OUT_4_CORPUS_LANGUAGE_PROOF.adoc`)

la gate de corpus. Décisions : la langue **ne bloque jamais** (`isClean` reste
la gate syntaxique) ; **mêmes surfaces** que le port (labels/directives, notes,
prose) ; source configurable (`-Pplantuml.corpusSourceLanguage`, défaut `fr`) ;
findings triés + JSON déterministe ; frontière `plantuml.corpus` pure, zéro LLM ;
les gates « zéro `@startuml` baké » / SVG sont **site/bakery** (hors plantuml).

== Preuve corpus (dogfooding réel, lecture seule, zéro LLM)

Consommateur transitoire `/tmp/opencode/plt-corpus-proof` (plugin 0.0.16 HEAD
via `publishToMavenLocal`) ; racine montée avec le segment `en/` (le
`CorpusLanguageResolver` lit la langue dans le chemin) :

[source,shell]
----
./gradlew validatePlantumlCorpus \
  -Pplantuml.corpusDir=/tmp/opencode/plt-corpus-root \
  -Pplantuml.corpusStrict=false
----

* **112 documents / 256 blocs** AsciiDoc EN mesurés.
* **43 blocs** portent un résidu de langue source, sur **23 documents** —
  concentration `0108` (8), `0106` (4), `0105`/`0110`/`0122` (3 chacun), plus les
  copies `pilot-batch` de `0100`/`0105`.
* **1 finding syntaxique** réel (`0095 line-80 — Missing or mismatched diagram
  delimiters`) : la gate syntaxique reste opérante, non bloquante ici via
  `strict=false`.
* Écart avec les **69 blocs** de S-076 : mesure différente (détecteur site
  `DiagramFrenchResidue` sur le **store** de blocs, 3 passes LLM, snapshot 2026-09)
  vs notre mesure sur le corpus AsciiDoc courant (surfaces du port, snapshot
  2026-11-05). Les deux mesurent le même phénomène ; la mesure plantuml est
  reproductible, gratuite, et fournit le « avant » du chantier cheroliv.
* **Commande « après »** (session cheroliv) : la même commande sur le même
  corpus, comparer `language residue (non-blocking)` et le JSON.
