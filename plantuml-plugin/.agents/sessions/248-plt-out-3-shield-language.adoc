== Mission

Deuxième incrément actionnable de `PLT-I18N-OUTPUT` après la gate de corpus
(PLT-OUT-1 ✅ S-246) et les notes (PLT-OUT-2 ✅ S-247). Rendre **impossibles**
deux faux verts mesurés sur cheroliv.com :

. un placeholder `__PLT<n>__` perdu par le fournisseur pouvait être écrit ;
. un label resté en français pouvait être déclaré `TRANSLATED`.

== Cadrage (`.agents/CADRAGE_PLT_OUT_3_SHIELD_LANGUE.adoc`)

Décisions : préservation **par surface** (label/note/prose) + gate de fuite de
placeholder au niveau du bloc ; détecteur de résidu **déterministe sans LLM**
(diacritiques français non ambigus + lexique non ambigu + ratio de mots-outils
≥ 0,30) ; biais assumé **préférer `PRESERVE` à un faux `TRANSLATED`** ; profil
indexé par langue source (seul `fr` livré, une autre source ne déclenche rien) ;
**retry borné à 2 tentatives** ; gate corpus **inchangée** (syntaxe ≠ langue) ;
frontière `plantuml.boundary` pure (zéro N0, zéro MEMPHIS, zéro tâche Gradle).

== Livré (baby-step DDD/TDD/BDD)

. **Domaine pur `SourceLanguageResidue`** (`plantuml.boundary`) — `detect(text,
  source, target): LanguageResidue(detected, evidence)`. Normalise `fr-FR` →
  `fr`, ignore les placeholders, retourne une évidence stable (`word:…`,
  `ratio:n/m`, `diacritic:…`). 17 unit.
. **Invariants placeholder sur `PlantumlTermShield`** — `leaksPlaceholder`
  et `introducesPlaceholder(translated, source)` (un fournisseur peut
  *inventer* un placeholder sur un label que le bouclier n'a pas touché : le
  chemin `restore` ne peut pas le voir). 5 unit.
. **Câblage `PlantumlTranslationPortAdapter`** — garde langue dans
  `translateProtected` (labels, notes, prose), rejet du lot si une partie est
  résiduelle (repli par label pour porter le retry borné), gate finale
  `introducesPlaceholder` → `Preserved("placeholder leak …")`, paramètre
  `maxTranslationAttempts` (défaut 2, plancher 1), aucune re-tentative sur un
  échec fournisseur ou un placeholder perdu (sémantique préservée). 10 unit.
. **Functional** (`PlantumlLanguageGuardFunctionalTest`, vrai
  `PlantumlSyntaxValidatorAdapter`) — résidu ⇒ bloc préservé et source valide ;
  bloc mixte (label traduit + note résiduelle) ⇒ `Translated`, zéro `__PLT`,
  bloc valide ; retry borné qui récupère ⇒ bloc valide.
. **BDD `@plantuml-language`** (`37_plantuml_language_guard.feature`, 6
  scénarios + `PlantumlLanguageGuardSteps` préfixés) — label court resté
  français, label accentué, retry récupère, retry s'arrête, source EN→FR non
  flaggée, placeholder inventé jamais écrit. Enregistrée dans le **shard E**
  (`CucumberShardFeatures` + `CucumberShardERunner`) — partition exhaustive et
  disjointe préservée (38 features, 37 assignées + `10_file_edge_cases` A1).
