== Mission

Le pilote constate que les diagrammes PlantUML des articles cheroliv.com ne sont
pas complètement traduits et que les termes métier/code (`integer`, identifiants,
fichiers) ne doivent jamais être traduits. Demande : améliorer le borough plantuml
puis reprendre les diagrammes incomplets. Méthode baby-step DDD/TDD/BDD.

== Cadrage

`.agents/CADRAGE_EPIC_PLT_TERM_PROTECTION.adoc` — US-1→4 ✅, US-5 (re-traduction
site) ⏳. Décisions : bouclier `__PLTn__`, prose non quotée, use cases/mindmaps,
fallback si placeholder perdu, N0 inchangé, tests unit/functional/BDD.

== Livré

* `PlantumlTermShield` : types primitifs, fichiers, chemins, options Gradle,
  identifiants, versions, couleurs, backticks, appels de fonction ; restauration
  ou label source préservé.
* `PlantumlProseLabelExtractor` : messages de séquence, activités, états, acteurs
  et cas d'usage, nœuds mindmap/WBS.
* `PlantumlTranslationPortAdapter` : labels + notes + prose, batching conservé,
  multi-label par ligne.
* Tests : `PlantumlTermShieldTest`, `PlantumlProseLabelExtractorTest`,
