== Livré (baby-step DDD/TDD/BDD)

=== Domaine pur `plantuml.corpus`

* `PlantumlCorpusBlock` — bloc `[plantuml]` (document, id, ligne, source).
* `CorpusLanguageResolver` — langue dérivée du chemin (premier segment égal à
  un code du N0 `LanguageCatalog` ; sinon `source` pour le pivot).
* `AsciiDocPlantumlCorpusScanner` — machine à états pure : `[plantuml,…]`,
  `[plantuml#id]`, délimiteurs `----` et `....`, ids quotes, ancre
  `[[id]]` précédente, id de repli `line-<n>` ; **ignore** `[source,plantuml]`,
  les blocs littéraux, les fences `////` et les lignes commentées.
* `PlantumlCorpusGate` — applique le port N0 `PlantUmlSyntaxValidator` à
  **chaque** bloc de **chaque** document ; tri déterministe
  (document, ligne, id) ; une exception du validateur devient une finding.
* `PlantumlCorpusBaseline` — baseline nommée : clé exacte
  `document\tblockId\treason` ou paire `document\tblockId` (raison libre),
  commentaires `#` ignorés.
* `PlantumlCorpusReport` — rapport reproductible (documents, blocs, invalides,
  baselinés, bloquants) + section « suggested baseline ».

=== Tâche Gradle `validatePlantumlCorpus`

* `ValidatePlantumlCorpusTask` : `-Pplantuml.corpusDir` (défaut `docs`),
  `-Pplantuml.corpusBaseline` (défaut `plantuml-corpus-baseline.txt`),
  `-Pplantuml.corpusStrict` (défaut `true`).
* Artefacts : `build/plantuml/plantuml-corpus-report.txt` (écrit **avant**
  l'échec) et `build/plantuml/plantuml-corpus-baseline.txt` (suggestions).
* Inputs/outputs Gradle déclarés → **UP-TO-DATE** prouvé ; `@DisableCachingByDefault`
  interdit le rejeu d'un rapport périmé.
* Enregistrée dans `PlantumlManager.Tasks` et **câblée à `check`** (gate réelle) ;
  i18n `task.corpus.*` + `corpus.*` dans les 10 langues.
