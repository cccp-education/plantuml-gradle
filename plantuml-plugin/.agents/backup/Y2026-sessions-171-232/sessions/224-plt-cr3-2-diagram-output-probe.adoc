== Constat (le vrai vecteur du « diagramme blanc »)

`PlantumlService.generateImage` **dégrade silencieusement** : en cas d'échec
PlantUML, il écrit le **texte source** (et l'erreur) **DANS** le `.png`
(lignes 54-66 du service) — un fichier **non vide qui n'est pas une image**.
Le test existant (`PlantumlServiceTest.should generate image`) ne vérifiait que
`outputFile.length() > 0` → **faux positif** : un « rendu blanc » passait vert.

C'est exactement la classe de défaut CHE-DIAGRAM (diagramme non rendu) mais
côté **production de l'artefact** par le plugin.
