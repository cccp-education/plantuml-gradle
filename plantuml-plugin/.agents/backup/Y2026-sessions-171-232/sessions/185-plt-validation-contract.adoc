== Contexte

document-gradle a un EPIC DOC-PLANTUML-VALIDATE (5 US, ~21 pts) BLOQUÉ sur
plantuml-gradle. Le `PlantUmlTranslationAdapter` de document traduit les labels
dans les blocs `[plantuml]` mais rien ne vérifie la syntaxe après traduction.

**Blocker** : `SyntaxValidationResult` était une sealed class **imbriquée** dans
`PlantumlService` — pas une API publique stable. Document a besoin d'un type
standalone consommable sans couplage à `PlantumlService`.

standalone avec `Valid` object + `Invalid` data class (errorMessage, stackTrace).
Suppression de la nested class dans `PlantumlService`.

Mise à jour de tous les imports dans les 3 tâches (ValidatePlantumlSyntaxTask,
GeneratePlantumlDiagramsTask, GenerateKnowledgeGraphDiagramTask) et
DiagramProcessor.

=== PLT-VAL-2 — KDoc (1 pt) ✅

KDoc public sur `SyntaxValidationResult`, `Valid`, `Invalid` et
`PlantumlService.validateSyntax()`. Documenté comme API publique stable
consommable par d'autres boroughs.
