== 2. US-6 — Chaîne de transmission E2E (3 pts)

*Objet* : un **scénario qui traverse la chaîne** sur un article réel à diagrammes et
vérifie : bloc extrait, labels traduits, **syntaxe valide (round-trip)**, **rendu non blanc**.

*Emplacement* : **bakery-gradle** (le maillon qui orchestre et exécute le bake). Deux
niveaux :
. **domaine/FT** (prioritaire) — étendre `MigrateContentI18nDeploySmokeFunctionalTest` /
  `CherolivComDogfoodingDryRunFunctionalTest` : après `migrateContentI18n`, le bloc
  `[plantuml]` traduit doit être **re-parsable** (validator N0) et les labels traduits
  présents (ex. `"User"` pour `"Utilisateur"`).
. **rendu** (le « non blanc ») — au **bake** (asciidoctor-diagram → SVG) : l'artefact
  SVG/PNG du diagramme doit passer `DiagramOutputProbe` (non vide + magic bytes →
  `Rendered`). *Outil disponible* : `plantuml.service.DiagramOutputProbe` (PLT-CR3-2,
N2→N2 interdit → porter l'assertion au niveau bakery : taille SVG > 0 et non-fallback).

*Assertions cibles* :
* bloc extrait (`[plantuml]` → `PlantUmlBlock`) ;
* labels traduits (le port a modifié le bloc) ;
* `validator.validate(translated) is Valid` (round-trip) ;
* artefact de rendu **non blanc** (SVG non vide, sans texte de fallback).

*Risque* : le bake réel nécessite la toolchain asciidoctor-diagram (lourde) — d'où un
niveau FT « contrat » (re-parse + labels) **sans** bake, et un niveau « rendu » gaté.

== 3. US-7 — Dogfooding + non-régression (2 pts)

*Objet* : re-baker **cheroliv.com** (article référence + variantes EN), vérifier
**zéro diagramme blanc/dégradé**, contrat final VERT.

*Emplacement* : **cheroliv.com** (site gouverné) — tâche de bake + garde
`DiagramIntegrity` (déjà cadrée côté site). *Protocole* : (1) bake référence (FR) ;
(2) bake variante EN ; (3) audit des SVG `[plantuml]` (non blanc, re-parse) ; (4)
`check` du site VERT. Aucune régression du contrat site.

== 4. Décisions

. **D-U6-1 — US-6 vit dans bakery-gradle** (orchestrateur/bake), pas dans plantuml
